# Jammed Develops Portfolio

This repository contains the source code for my personal portfolio website, showcasing my projects, skills, and professional background.

## Features

- **Single-Page Portfolio**: A fast, interactive experience highlighting my work in development, design, and motion.
- **Projects**: Detailed insights into my ongoing and completed projects, ranging from mobile applications to content creation.
- **Responsive Design**: Optimized for various devices to ensure a seamless viewing experience.

## Deployment

This portfolio is deployed and hosted on **Netlify**.
